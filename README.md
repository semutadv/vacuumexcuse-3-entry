One line, at most 140 characters: the funniest excuse a robot vacuum could
offer for missing a spot. This entry denies the miss entirely — the spot is
where the vacuum keeps its dignity, visited emotionally every day at 3 a.m.,
which any tired homeowner will recognise as exactly when the machine wakes
up and bumps into the furniture.

`main.ts` (Node 22, no dependencies) writes the excuse to `entry.txt` in
the output directory, clearing the directory's contents first and adding no
trailing newline.
